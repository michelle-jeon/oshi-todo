# 버저닝

OshiTodo는 작게 시작하되, 나중에 작업 흐름을 되짚을 수 있도록 간단한 시맨틱 버저닝을 사용한다.

```text
MAJOR.MINOR.PATCH
```

## 공개 전 버전 기준

- `0.1.x`: 로컬 MVP 뼈대와 초기 플레이 가능 프로토타입
- `0.2.x`: 다른 사람에게 보여줄 수 있는 웹 MVP
- `0.3.x`: 캐릭터, 옷장, 상점, 밸런스 고도화
- `0.4.x`: 데스크톱 작업 시간 추적, PWA, 모바일 실험
- `1.0.0`: 첫 공개 릴리스

## 언제 올릴지

- 패치(`PATCH`): 버그 수정, 문구 수정, 작은 UI 정리
- 마이너(`MINOR`): 캘린더, 루틴, 친구, 광장처럼 사용자가 체감하는 기능 추가
- 메이저(`MAJOR`): 공개 이후 데이터 모델이나 사용 방식이 크게 깨지는 변경

## 현재 운영 방식

- 의미 있는 기능 묶음이 끝나면 `package.json`의 `version`을 올린다.
- `CHANGELOG.md`에는 `버전 - 날짜` 섹션을 만들고, 그 버전에 포함된 변경 사항을 옮겨 적는다.
- `CHANGELOG.md`의 `다음 릴리스 준비 중`은 아직 버전을 올리지 않은 작업만 임시로 적는다.
- 버전을 올린 뒤에는 `다음 릴리스 준비 중`에 남은 항목이 없는지 확인한다.
- `docs/VERSIONING.md`에는 현재 버전과 릴리스 흐름을 남긴다.
- 커밋 메시지는 기능 단위로 남긴다.
- 나중에 중요한 지점은 `v0.2.0`처럼 Git 태그를 붙인다.

## 현재 버전

- `0.2.18`: 첫 캐릭터 생성 화면 보조 로그인 버튼 톤다운과 루틴 XP 보상 설정.

## 릴리스 기록

- `0.2.18` - 첫 캐릭터 생성 화면의 다른 계정 로그인 버튼을 밑줄 버튼으로 낮추고, 루틴별 XP 보상 설정과 표시 추가.
- `0.2.17` - 캐릭터 `...` 버튼과 계정 메뉴 버튼의 드롭다운 클릭 처리와 메뉴 레이어 순서를 안정화.
- `0.2.16` - 루틴 종료용 `ends_on` 컬럼이 DB에 없을 때 실행할 SQL Editor 파일을 홈 안내에서 직접 표시.
- `0.2.15` - 로그인 직후 스플래시 추가, 루틴 시작일 UTC 밀림 수정, 날짜 기준 루틴 종료와 투두/루틴 조회 인덱스 추가.
- `0.2.14` - 작업시간 더미 SQL에 `target_user_id_input`을 추가해 특정 profile에 더미 기록을 넣을 수 있게 함.
- `0.2.13` - 활성 캐릭터가 없는 profile에도 작업시간 더미 기록이 들어가도록 최근 캐릭터 활성화와 더미 캐릭터 생성을 추가.
- `0.2.12` - 작업시간 SQL Editor 실행 파일을 3단계로 분리하고 함수 복사 오류 가능성을 줄임.
- `0.2.11` - 작업시간 로그 테이블, 저장 함수, 조회 인덱스, 더미 기록을 한 번에 실행하는 SQL Editor용 통합 SQL 추가.
- `0.2.10` - 작업시간 과거 기록 더미 SQL과 작업시간/XP/상점/친구/광장 조회용 인덱스 migration 추가.
- `0.2.9` - 작업시간 로그 migration이 없어도 홈 화면에 DB 스키마 안내가 계속 뜨지 않게 방어 처리.
- `0.2.8` - 옷장 탭에서 보유 아이템이 없을 때 불필요한 빈 상태 문구를 숨김.
- `0.2.7` - 옷장에서 보유 아이템 목록을 읽고 구매한 캐릭터 아이템을 장착해 저장하는 흐름 추가.
- `0.2.6` - Turbopack 개발 서버 패닉을 피하도록 webpack 개발 모드로 고정하고, 세션 없는 보호 페이지의 인증 API 반복 호출을 차단.
- `0.2.5` - 캐릭터 목록, 생성, 옷장까지 캐릭터 레이어 이미지를 일반 이미지 렌더링으로 통일.
- `0.2.4` - 캐릭터 레이어 이미지의 Next 이미지 런타임 반복 반응과 개발 중 깜빡임 정리.
- `0.2.3` - Google 로그인 버튼 반복 초기화와 라우터 초기화 전 이동 오류 정리.
- `0.2.2` - 상점, 광장, 캐릭터 방 이동 중 인증 오류 처리 안정화와 상점 미리보기 리렌더 방지.
- `0.2.1` - 투두/루틴 낙관적 UI 실패 복구, 서버 액션 오류 표시, 백로그/버전 기록 정리.
- `0.2.0` - 다른 사람에게 보여줄 수 있는 웹 MVP 기준선.
- `0.1.0` - 로컬 MVP 뼈대와 초기 플레이 가능 프로토타입.
