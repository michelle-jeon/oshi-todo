# MVP 이후 백로그

MVP가 끝난 뒤 고칠 것과 고도화할 기능을 모아두는 문서입니다.  
한국어를 기준으로 적고, 필요한 경우 표준 기술 용어만 괄호로 덧붙입니다.

## 인증

- ✅ 보호 페이지 이동 중 인증 확인이 반복되거나 로그인 화면으로 튕기는 흐름 정리.
  - 인증 세션 없음과 인증 서버 일시 오류를 구분해서 처리.
  - 상점, 광장, 캐릭터 방에서 사용자 범위를 명확히 제한.
- 추가 소셜 로그인 검토.
  - Kakao 로그인.
  - Naver 로그인.
  - X/Twitter 로그인.
  - Apple 로그인.
  - 필요하면 GitHub 로그인.
- 운영 배포 전에 인증 화면의 외부 이동 문구를 브랜드 도메인 중심으로 정리.
  - Supabase Custom Domain 또는 별도 auth 도메인 검토.
  - Google OAuth consent screen의 앱 이름과 로고 정리.
- OshiTodo 앱 로고 제작 후 인증/브랜딩 설정에 반영.
  - Google OAuth consent screen 로고 등록.
  - 앱 파비콘과 소셜 공유 이미지에도 같은 방향성 적용.
- 계정 설정 페이지.
  - 연결된 소셜 계정 확인. (기본 화면 추가 완료)
  - 추가 provider 연결/해제.
  - 계정 삭제.

  - ✅ 새 인간 기본 레이어 에셋으로 교체하고 바디, 신발, 하의, 상의, 헤어, 입, 눈, 악세서리 카테고리로 분리.
  - ✅ 캐릭터 생성, 옷장, 상점에서 같은 카테고리 순서와 아이콘을 사용.
  - ✅ 아이템별 `layerOrder`로 하이탑 신발처럼 기본 카테고리 순서와 다른 합성 순서를 지원.
  - 현재 원본 경로는 `public/assets/characters/human/layers/{category}/*`.
  - 새 아이템 추가 규칙은 `docs/CHARACTER_ASSETS.md`를 기준으로 유지.
  - ✅ 캐릭터 생성, 옷장, 상점 아이템을 이미지 카드 형식으로 통일.
  - ✅ 헤어와 눈의 같은 스타일·다른 색상은 한 아이템 카드와 원형 색상 선택 UI로 통합.

  - 옷장 화면에서 이름 변경 가능. (기본 구현 완료)

  - 보유 아이템 목록 보기.
  - 구매한 아이템 장착.

- 다중 캐릭터 지원.
  - 새 캐릭터 생성.
  - 캐릭터 슬롯 화면.
  - 기본 캐릭터 변경.
  - 캐릭터마다 XP와 인벤토리 분리.
- 아바타 종류 확장.
  - 강아지.
  - 엘프.
  - 요정.
  - 기타 판타지 종족.

  - 헤어스타일.
  - 머리 색.
  - 눈 색.

  - 예: 색상에 따라 리본 모양이 하트로 바뀌는 작은 차이.

## XP와 재화

- ✅ 누적 경험치와 사용 가능한 재화를 더 명확히 분리.
- ✅ 누적 경험치는 홈 상단에서 숨기고, 계정 설정의 XP/재화 기록에서 확인하도록 정리.
- ✅ 작업창 XP를 데스크톱 앱 수준으로 고도화.
  - 웹 MVP에서는 브라우저 보안 제한 때문에 외부 앱의 실제 포커스 상태를 정확히 알 수 없음.
  - Electron PC 앱에서 열린 창을 고르고, 선택한 창이 실제 활성 상태일 때만 작업시간과 XP를 기록.
  - macOS, Windows, Linux별 활성 창 확인 경로를 추가하고 웹에서는 기존 화면 공유 방식을 유지.
  - 후속으로 창 제목 변경 대응과 장시간 비활성 상태 감지를 더 정교하게 보강.
- ✅ 상점 구매 플로우 추가.
  - ✅ 중복 구매 방지.
  - ✅ 사용 가능한 XP 차감.
  - ✅ 구매 아이템을 캐릭터 인벤토리에 추가.
- ✅ 아이템 장착/해제 플로우 추가.
  - 옷장에서 기본/없음 아이템으로 해제할 수 있게 유지.
  - 장착 저장 시 현재 활성 캐릭터가 실제로 보유한 아이템 또는 기본값만 허용하도록 서버 검증 추가.
  - 저장 중/변경 없음 버튼 상태를 정리해 중복 저장 가능성을 줄임.
- XP 보상 밸런싱.
  - ✅ 투두/루틴 난이도를 `가벼움/보통/도전`으로 고르고 고정 XP를 받게 단순화.
    - ✅ 투두나 루틴을 작성할 때 난이도를 고를 수 있게 하고, 기본값은 `보통`으로 유지.
    - `가벼움`은 5XP, `보통`은 20XP, `도전`은 50XP로 적용.
    - ✅ 난이도별 XP 수치는 생성/수정 화면과 투두/루틴 목록에서 숨기고, 실제 완료 결과로 확인하게 정리.
    - 난이도 변경은 할 일 상세와 루틴 수정 모달에서 처리.
    - AI XP 추천 호출과 API 키 의존성을 제거해 비용과 설정 부담을 줄임.
  - ✅ 기본 상한과 일일 획득량 제한으로 인플레이션 방지.
    - 하루 획득 XP 상한을 500XP로 두고, 투두/루틴 완료와 작업창 XP 지급을 같은 한도 안에서 처리.
    - 상한을 넘으면 완료 자체는 유지하고 실제 지급 XP만 남은 한도만큼 줄이도록 DB 함수에서 제한.
    - 홈 상단에 오늘 획득 XP와 하루 상한을 표시.
  - 데일리 보너스.
  - 연속 완료 보너스.
- ✅ XP 획득/사용 기록 화면 페이지네이션과 레이지 로딩 추가.
  - 첫 화면은 최근 기록 일부만 보여주고, 아래로 스크롤하면 다음 기록을 자동으로 불러오게 함.
  - ✅ offset 대신 커서 기반으로 다음 묶음을 조회하고, 불러온 기록 요약/스켈레톤/지연 렌더링/DB 인덱스를 보강.

## 작업시간 기록과 통계

- ✅ 작업시간 통계 대시보드 1차 추가.
  - 계정 설정에서 작업시간 기록 화면으로 이동할 수 있게 하고, 오늘/이번 주/이번 달 작업시간, 기록일 평균, 최근 14일 추이, 이번 달 많이 한 작업을 표시.
  - 이번 달 총 작업량.
  - 이번 달 기록일 평균 작업시간.
  - 날짜별 작업시간 추이.
  - 후속으로 기간 필터와 상세 보기 연결 필요.
  - ✅ 요일별 작업량 비교.
- ✅ 작업 이름별 통계.
  - 작업시간 기록 화면에서 이번 달 기록을 작업 이름 기준으로 합산하고, 누적 시간/XP/비중을 함께 표시.
  - 같은 이름의 작업창은 하나로 합쳐서 집계.
  - 작업 이름별 누적 시간과 XP.
  - 도넛 그래프로 작업 비중 표시.
- 캘린더 기반 작업 기록 고도화.
  - 특정 날짜에 어떤 작업을 얼마나 했는지 상세 보기.
  - 월간 캘린더에서 작업량이 많은 날을 더 눈에 띄게 표시.
  - 날짜별 총 작업시간/작업 종류 수/획득 XP 표시.
- ✅ 통계 필터.
  - 작업시간 기록 화면에 기간, 작업 이름, 캐릭터 필터를 추가하고 선택한 조건 기준으로 요약/날짜별 기록/작업 이름별 통계를 다시 계산.
  - 기간 필터: 오늘, 이번 주, 이번 달, 사용자 지정 기간.
  - 작업 이름 필터.
  - 캐릭터별 필터.
- ✅ 작업시간 회고 UX.
  - 작업시간 기록 화면에서 선택한 필터 기준으로 가장 많이 한 작업, 가장 집중한 요일, 직전 같은 길이 기간 대비 증감을 문장으로 요약.
  - 가장 많이 한 작업.
  - 가장 집중한 요일.
  - 지난주 대비 증감.
  - "이번 달에는 인프런을 가장 많이 봤어요" 같은 요약 문장.

## 투두 시스템

- ✅ 마감일 추가.
  - ✅ 투두 생성 시 마감일은 기본적으로 비워두고, 필요한 경우에만 입력할 수 있게 정리.
  - 투두 생성과 할 일 상세에서 마감일을 입력하고 수정하거나 제거할 수 있게 연결.
  - 목록에서는 오늘 마감/지난 마감/이후 마감을 작은 배지로 표시.
  - `due_date` DB 스키마가 없을 때 기존 조회는 유지하고, 마감일 수정 시 SQL Editor 안내를 표시.
- ✅ 우선순위 추가.
  - 투두 생성과 할 일 상세에서 `낮음/보통/높음` 우선순위를 고르고 수정할 수 있게 연결.
  - 투두 목록에는 XP와 별도로 작고 흐릿한 우선순위 배지를 표시해 난이도와 역할이 겹치지 않게 정리.
  - 우선순위 DB 스키마가 없을 때는 기본값 `보통`으로 fallback하고 SQL Editor 안내를 표시.
- 태그/카테고리 추가.
- 루틴 고도화.
  - 루틴을 해당 날짜의 실제 투두로 완료 처리하기.
  - ✅ 루틴 시작일을 생성한 날짜부터 적용.
  - ✅ 선택한 날짜부터 루틴 종료.
  - ✅ 루틴별 XP 보상 설정.
  - ✅ 루틴 난이도 설정.
  - 격주/매월/특정 기간 반복.
  - 루틴 일시정지.
- ✅ 메모/상세 설명 추가.
  - 투두 생성 시 메모를 함께 입력할 수 있게 함.
  - 할 일 상세에서 메모를 수정하고, 완료한 할 일에서는 읽기 전용으로 확인.
  - 목록에서는 메모가 있을 때 한 줄 미리보기만 표시.
- ✅ 완료한 투두 아카이브 화면.
  - 완료 기록을 30개 단위로 불러오고, 아래로 스크롤하면 다음 기록을 자동으로 불러오게 함.
- ✅ 완료 취소 UX 더 다듬기.
  - 투두와 루틴 완료 후 저장 성공 안내에 `되돌리기` 버튼을 제공해 바로 완료 취소할 수 있게 함.
- ✅ 낙관적 UI 적용.
  - 완료/취소/삭제가 더 즉각적으로 보이게 하기.
  - 서버 액션 실패 시 이전 UI 상태로 복구하고 화면 안에서 오류 메시지를 보여주기.
  - ✅ 삭제 버튼도 투두를 클릭해서 나오는 상세에서 삭제할 수 있도록 변경.
- ✅ 루틴과 투두 생성 기능을 `+` 버튼으로 토글되게 정리.
  - 홈에서는 기본적으로 추가 패널을 접어두고, 필요할 때만 투두/루틴 생성 폼이 보이게 함.
  - ✅ 할 일과 루틴 생성 첫 행을 제목 입력과 추가 아이콘만 남기도록 정리.
  - ✅ 할 일 난이도를 연결형 3단계 라디오 UI로 바꾸고 우선순위와 구분.
  - ✅ 할 일 메모 입력을 생성 폼 마지막의 전체 너비 장문 입력으로 배치.
