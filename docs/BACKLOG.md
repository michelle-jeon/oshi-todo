# MVP 이후 백로그

MVP가 끝난 뒤 고칠 것과 고도화할 기능을 모아두는 문서입니다.  
한국어를 기준으로 적고, 필요한 경우 표준 기술 용어만 괄호로 덧붙입니다.

## 인증

- ✅ 보호 페이지 이동 중 인증 확인이 반복되거나 로그인 화면으로 튕기는 흐름 정리.
  - 인증 세션 없음과 인증 서버 일시 오류를 구분해서 처리.
  - 상점, 광장, 캐릭터 방에서 사용자 범위를 명확히 제한.
- 추가 소셜 로그인 검토.
  - Kakao 로그인.
  - Naver 로그인.
  - X/Twitter 로그인.
  - Apple 로그인.
  - 필요하면 GitHub 로그인.
- 운영 배포 전에 인증 화면의 외부 이동 문구를 브랜드 도메인 중심으로 정리.
  - Supabase Custom Domain 또는 별도 auth 도메인 검토.
  - Google OAuth consent screen의 앱 이름과 로고 정리.
- OshiTodo 앱 로고 제작 후 인증/브랜딩 설정에 반영.
  - Google OAuth consent screen 로고 등록.
  - 앱 파비콘과 소셜 공유 이미지에도 같은 방향성 적용.
- 계정 설정 페이지.
  - 연결된 소셜 계정 확인. (기본 화면 추가 완료)
  - 추가 provider 연결/해제.
  - 계정 삭제.

## XP와 재화

- ✅ 누적 경험치와 사용 가능한 재화를 더 명확히 분리.
- ✅ 누적 경험치는 홈 상단에서 숨기고, 계정 설정의 XP/재화 기록에서 확인하도록 정리.
- 작업창 XP를 데스크톱 앱 수준으로 고도화.
  - 웹 MVP에서는 브라우저 보안 제한 때문에 외부 앱의 실제 포커스 상태를 정확히 알 수 없음.
  - Electron/Tauri/macOS 권한을 써서 선택한 앱/창이 실제 활성 상태일 때만 XP 지급.
  - 백그라운드 딴짓 감지와 부정 적립 방지 로직 추가.
- ✅ 상점 구매 플로우 추가.
  - ✅ 중복 구매 방지.
  - ✅ 사용 가능한 XP 차감.
  - ✅ 구매 아이템을 캐릭터 인벤토리에 추가.
- ✅ 아이템 장착/해제 플로우 추가.
  - 옷장에서 기본/없음 아이템으로 해제할 수 있게 유지.
  - 장착 저장 시 현재 활성 캐릭터가 실제로 보유한 아이템 또는 기본값만 허용하도록 서버 검증 추가.
  - 저장 중/변경 없음 버튼 상태를 정리해 중복 저장 가능성을 줄임.
- XP 보상 밸런싱.
  - ✅ 투두/루틴 난이도를 `가벼움/보통/도전`으로 고르고 고정 XP를 받게 단순화.
    - ✅ 투두나 루틴을 작성할 때 난이도를 고를 수 있게 하고, 기본값은 `보통`으로 유지.
    - `가벼움`은 5XP, `보통`은 20XP, `도전`은 50XP로 적용.
    - 투두 목록에서는 XP만 작게 표시하고, 난이도 변경은 할 일 상세와 루틴 수정 모달에서 처리.
    - AI XP 추천 호출과 API 키 의존성을 제거해 비용과 설정 부담을 줄임.
  - ✅ 기본 상한과 일일 획득량 제한으로 인플레이션 방지.
    - 하루 획득 XP 상한을 500XP로 두고, 투두/루틴 완료와 작업창 XP 지급을 같은 한도 안에서 처리.
    - 상한을 넘으면 완료 자체는 유지하고 실제 지급 XP만 남은 한도만큼 줄이도록 DB 함수에서 제한.
    - 홈 상단에 오늘 획득 XP와 하루 상한을 표시.
  - 데일리 보너스.
  - 연속 완료 보너스.
- ✅ XP 획득/사용 기록 화면 페이지네이션과 레이지 로딩 추가.
  - 첫 화면은 최근 기록 일부만 보여주고, 아래로 스크롤하면 다음 기록을 자동으로 불러오게 함.

## 작업시간 기록과 통계

- 작업시간 통계 대시보드.
  - 이번 달 총 작업량.
  - 이번 주/이번 달 평균 작업시간.
  - 날짜별 작업시간 추이.
  - 요일별 작업량 비교.
- 작업 이름별 통계.
  - 같은 이름의 작업창은 하나로 합쳐서 집계.
  - 작업 이름별 누적 시간과 XP.
  - 도넛 그래프로 작업 비중 표시.
- 캘린더 기반 작업 기록 고도화.
  - 특정 날짜에 어떤 작업을 얼마나 했는지 상세 보기.
  - 월간 캘린더에서 작업량이 많은 날을 더 눈에 띄게 표시.
  - 날짜별 총 작업시간/작업 종류 수/획득 XP 표시.
- 통계 필터.
  - 기간 필터: 오늘, 이번 주, 이번 달, 사용자 지정 기간.
  - 작업 이름 필터.
  - 캐릭터별 필터.
- 작업시간 회고 UX.
  - 가장 많이 한 작업.
  - 가장 집중한 요일.
  - 지난주 대비 증감.
  - "이번 달에는 인프런을 가장 많이 봤어요" 같은 요약 문장.

## 운영과 개발환경

- ✅ 상점, 광장, 캐릭터 방 진입 시 개발 서버 렌더 요청이 반복되는 문제 정리.

- ✅ 상점 아이템 seed 스크립트 추가.
  - `npm run seed:shop-items`와 SQL Editor용 `supabase/sql_editor/09_shop_items_seed.sql`로 상점 아이템 upsert 흐름을 정리.
- Supabase CLI 기반 migration workflow 더 정리. (기본 문서화 완료)
- staging/production Supabase 프로젝트 분리.
- 개발 브랜치와 운영 브랜치 분리. (토요일 작업 후보)
