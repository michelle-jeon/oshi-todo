# MVP 이후 백로그 / Post-MVP Backlog

MVP가 끝난 뒤 고칠 것과 고도화할 기능을 모아두는 문서입니다.  
한국어를 기준으로 적고, 필요한 경우 영어 설명을 괄호로 덧붙입니다.

## 인증 / Auth

- 비밀번호 찾기 기능 추가.
  - `/login`에 "비밀번호를 잊으셨나요?" 링크 추가.
  - Supabase password recovery 이메일 사용.
  - 복구 링크로 돌아온 사용자가 새 비밀번호를 입력하는 페이지 추가.
- 이메일 인증 UX 개선.
  - "메일을 확인해 주세요", "인증 완료, 이제 로그인하세요" 같은 상태를 더 명확히 보여주기.
- 소셜 로그인 검토.
  - 이메일/비밀번호 MVP가 안정화된 뒤 Google 로그인부터 고려.
- 계정 설정 페이지.
  - 이메일 변경.
  - 비밀번호 변경.
  - 계정 삭제.

## 캐릭터 시스템 / Character System

- 캐릭터 이름 변경 기능.
- 캐릭터 옷장 기능.
  - 보유 아이템 목록 보기.
  - 구매한 아이템 장착/해제.
  - 색상 변경은 홈이 아니라 옷장에서만 가능하게 유지.
- 다중 캐릭터 지원.
  - 새 캐릭터 생성.
  - 캐릭터 슬롯 화면.
  - 기본 캐릭터 변경.
  - 캐릭터마다 XP와 인벤토리 분리.
- 아바타 종류 확장.
  - 강아지.
  - 엘프.
  - 요정.
  - 기타 판타지 종족.
- 인간 캐릭터 커스터마이징 확장.
  - 헤어스타일.
  - 머리 색.
  - 눈 색.
  - 피부 색.
  - 옷과 옷 색상.
  - 악세서리.
  - 얼굴 표정.
  - 체형.
  - 탈 것과 탈 것 색상.
- 색상/아이템별 디테일 변형.
  - 예: 색상에 따라 리본 모양이 하트로 바뀌는 작은 차이.

## XP와 재화 / XP And Economy

- 누적 경험치와 사용 가능한 재화를 더 명확히 분리.
- 작업창 XP를 데스크톱 앱 수준으로 고도화.
  - 웹 MVP에서는 브라우저 보안 제한 때문에 외부 앱의 실제 포커스 상태를 정확히 알 수 없음.
  - Electron/Tauri/macOS 권한을 써서 선택한 앱/창이 실제 활성 상태일 때만 XP 지급.
  - 백그라운드 딴짓 감지와 부정 적립 방지 로직 추가.
- 상점 구매 플로우 추가.
  - 중복 구매 방지.
  - 사용 가능한 XP 차감.
  - 구매 아이템을 캐릭터 인벤토리에 추가.
- 아이템 장착/해제 플로우 추가.
- XP 보상 밸런싱.
  - 할 일 난이도별 XP.
  - 데일리 보너스.
  - 연속 완료 보너스.
- XP 획득/사용 기록 화면.
